# DD-14 — نموذج المستأجر للمعمل

- **الحالة:** مقبول
- **التاريخ:** 2026-08-10

## السياق (Context)

- يجب تحديد ما إذا كان النظام يعزل بيانات معامل متعددة.

## القرار (Decision)

النظام **أحادي المعمل (single-tenant)**؛ لا يوجد عزل بيانات متعدد المعامل.

## النتائج (Consequences)

- لا تُضاف مفاتيح أو مرشحات عزل المستأجر إلى نموذج البيانات.
